SORT 2.28.1 - Version-label hotfix
=================================
New patch build: 35fdd29c35745570ced3426df118a81a2322eb82234e11f4fd5c543666375d31

This is a small patch for your existing SORT installation, NOT a standalone
extension. It changes only diagnostics.js, popup.js and build-info.js.
The supplied source versions matched the installed hashes in your support export
before modification. If you edited these files since exporting, review/merge the
changes rather than overwriting those later edits.

APPLY
1. Finish recording and wait for saves/uploads to finish.
2. Back up your unpacked extension folder. Close SORT player, capture, ticket,
   import and other extension windows.
3. Copy the three JS files from this ZIP into that same extension folder,
   replacing their previous versions.
4. Keep your manifest.json at 2.28.1. The manifest is intentionally NOT included.
   defaults.js, credentials, icons, libraries and recordings are not changed.
5. Reload SORT in chrome://extensions. Do not uninstall it.
6. Refresh your work tabs so they receive the new isolated content scripts.
7. Open Settings > Support. Confirm the displayed version is 2.28.1.
8. Export fresh support logs and open them with the separate offline viewer.

EXPECTED RESULT
- New export filename begins SORT-support-2.28.1-.
- release.version, workerBuild.version and installedAtExport.version are 2.28.1.
- New events from refreshed contexts carry emitter.version = 2.28.1.
- Previously persisted entries retain their original 2.26.11 labels. This is
  intentional: the hotfix does not rewrite history or pretend old context
  metadata was correct. The viewer lets you filter by event version.
- packageBuild changes to identify this patch. installedFingerprint changes
  because the installed code changed; it also reflects local deployment files.

FUTURE VERSION CHANGES
All user-visible version labels and new event versions now read Chrome's
manifest through chrome.runtime.getManifest().version. Change manifest.json and
reload the extension/refresh tabs when releasing a new version. You no longer
need to update a second version label in build-info.js to get accurate exports.
The static packageBuild remains the shipped-package identifier. Local code edits
are captured by installedFingerprint, independently of packageBuild. A future
packaged release may regenerate its static build metadata as part of packaging.

OFFLINE VIEWER
The separately supplied HTML file is standalone. Save it anywhere outside the
extension folder and open it in Chrome; no extension installation or server is
required. Use Open support JSON or drop a JSON file into the page.
- Search event fields with one or more space-separated terms.
- Filter by component, operation, outcome, severity, event version or time.
- Select an operation to see full details and five events before/after it,
  regardless of active filters. Event proximity is not proof of causation.
- Switch between UTC and local time. Switching clears time filters explicitly.
- Save filtered text produces a human-readable report, not a replacement JSON.
- Build metadata and file inventory remain collapsed until you expand them.
- Hash verification checks consistency of the JSON inventory, not installed
  source files on another computer and not the authenticity of the sender.
- Supports one schema-1 support export at a time, up to 20 MiB/20,000 events.
- No network requests, accounts, external libraries or persistent browser state.
  Original JSON remains unchanged. Close/reload/unload clears the page's copy.

VALIDATION
15 diagnostic test groups passed, including a simulated future manifest version
with stale build metadata and preservation of historical event labels.
Viewer logic was checked with your actual 74-event export using DOM/API mocks:
search/filters, UTC date ranges, event context, pagination, readable-text output,
invalid/oversized files, safe text rendering and inventory hash verification.
All changed JavaScript and the viewer script passed syntax checks.
Live Chrome rendering, file downloads and extension reload have not been tested
in this environment. Run the short install/export check above on your computer.

SCOPE
This patch fixes version labeling only. It does not change call polling behavior,
retention limits, deduplication counters or the potential post-stop tab-injection
race identified in your earlier log review.
